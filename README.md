## 🚀 Getting Started

Every simulation in this repository includes a standalone `index.html` file that can be opened directly in any modern browser without needing a build step or server:

```bash
# Clone the repository
git clone https://github.com/procanimation/science-stuff.git
cd science-stuff

# Open the 3D Lorenz Attractor
open lorenz_attractor/index.html
```
